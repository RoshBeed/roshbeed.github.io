# roshbeed.com

My personal site: a home page, a CV, and a blog. Published to GitHub Pages on
every push to `main`.

## The blog

Write-ups of things I build, one post per project. Most of them work through the
[Machine Learning Institute](https://ml.institute) residency, with a couple going
deeper into a single question that came out of one.

Each post carries a small model, trained when the post is written, so the figures
are the output of code you can read next to them rather than screenshots of a run
that happened somewhere else. The projects themselves live in
[RoshBeed/ai-residency](https://github.com/RoshBeed/ai-residency).
